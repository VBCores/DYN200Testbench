# CSV DYN-200

`log_dyn200_csv` записывает файл `dyn200.csv` с колонками:

```text
host_time_ms,subject_id,value,unit
```

`host_time_ms` — монотонное время ПК в миллисекундах, полезное для относительного времени и сортировки, но не календарная метка. `5100` имеет единицу `rpm`, `5101` — `Nm`. Сообщения независимы; соседние строки не являются одной синхронной пробой.
